# Getting help

agent-kernel is a free, open-source project maintained by volunteers. There is no paid support.

1. **Look first:** [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) and the [FAQ](docs/FAQ.md). Most problems show in the agent's log or in a notice it sent you.
2. **Ask your own AI assistant:** [SETUP-WITH-AI.md](docs/SETUP-WITH-AI.md) is a prompt that walks it through this project's guides.
3. **Open an issue** on [GitHub](https://github.com/pixan-ai/agent-kernel/issues) with the symptom, the host, the version and the log lines around the problem.

**Never paste a key, a token or the contents of `.env`**, in an issue or anywhere else. A log line from the agent is safe to share: it never prints them.

Security problems: [SECURITY.md](SECURITY.md), privately, not in an issue.
