# 0004. A required weekly review

**Status:** Accepted (2026-11-25).

**Decision.** The owner or a super-user reviews every agent at least once a week: the notices, the installed tools and settings, the conversations and the log. Whoever operates the agents is responsible for it.

**Why.** Much of what keeps an agent safe is an instruction its model judges, and code only tells the owner after the fact. What code does not prevent, a person must look for. Keeping the code small (0001, 0002) makes this the honest place for the rest.

**Cost.** The review finds problems late and prevents none. Agents with the most power stay out of open groups.
