# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment, insults and personal attacks are not accepted, in issues, pull requests or any other project space.

## Reporting

To report behaviour privately, open a public issue that says only "I have a conduct report, please contact me", with no details, and a maintainer will arrange a private channel. Reports are handled confidentially. Maintainers may remove comments, lock threads or block participants who break this code.

Security problems are not conduct reports: see [SECURITY.md](SECURITY.md).
